## Дослідження авторизації та API-передумов у Dojo Articles

### 1. Зберігання стану авторизації

Застосунок Dojo Articles зберігає JWT у `localStorage` за ключем `qa-dojo.token`.

Це було визначено через DevTools → Application → Local Storage після авторизації користувача.

Додатково механізм перевірено в автоматизованому тесті: токен встановлюється через `context.setStorageState()`, після чого користувач може працювати із застосунком без повторного входу через UI.

### 2. Авторизація та передавання токена

Для входу використовується запит:

`POST /api/users/login`

Структура request body:

```json
{
  "user": {
    "email": "...",
    "password": "..."
  }
}
```

У відповіді сервер повертає об'єкт `user`, який містить JWT у полі `token`.

Для наступних авторизованих API-запитів застосунок передає токен у HTTP-заголовку:

`Authorization: Token <JWT>`

Це було перевірено через DevTools → Network під час оновлення налаштувань профілю (`PUT /api/user`).

### 3. UI-сценарії з підготовкою передумов через API

**Сценарій 1. Редагування статті**

- **Передумови:** авторизований користувач і створена ним стаття.
- **API-підготовка:** створити користувача через `POST /api/users`, отримати JWT і створити статтю через `POST /api/articles`.
- **UI-дія:** відкрити створену статтю, змінити її заголовок або текст через інтерфейс і зберегти зміни.
- **Перевірка:** переконатися, що оновлені дані відображаються на сторінці статті.

**Сценарій 2. Додавання статті до Favorites**

- **Передумови:** авторизований користувач і доступна йому стаття.
- **API-підготовка:** створити користувача через `POST /api/users`, отримати JWT і створити статтю через `POST /api/articles`.
- **UI-дія:** відкрити статтю в браузері та натиснути кнопку додавання до Favorites.
- **Перевірка:** переконатися, що стаття з'явилася у списку Favorites користувача.

В обох сценаріях API використовується лише для підготовки тестових даних і стану авторизації. Основна дія, яку перевіряє тест, виконується через UI.

## Запуск тесту

Встановіть залежності проєкту (`npm install`) та запустіть із кореневої директорії:

```bash
npx playwright test tests/api/avatar.spec.ts
```
